# TXMusic

Player local premium para Android com tema roxo, biblioteca por músicas/artistas/álbuns, favoritos, playlists, recentes, edição interna de metadados, player em segundo plano e notificação com controles.

## Gerar APK pelo GitHub Actions

1. Envie o conteúdo desta pasta para a raiz de um repositório no GitHub.
2. Abra a aba Actions.
3. Rode o workflow Build Android APK.
4. Baixe o artifact TXMusic-debug-apk.

O APK ficará dentro do artifact como `app-debug.apk`.
